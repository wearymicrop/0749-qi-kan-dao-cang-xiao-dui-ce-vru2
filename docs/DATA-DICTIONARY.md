# 数据字典

## 输入清册

输入为 UTF-8 JSON 对象，字段 `rules`、`titles`、`receipts` 分别为三张数组，可选字段 `specs` 为出版说明数组。对应单表上限 3000 行，生成应到期位上限 10000。原始行号从 `receipts` 首个数组项起算，首项为 1。

| 表 | 字段 | 定义 |
|---|---|---|
| 订购 | `chain` | 稳定订阅链字符串，区分大小写 |
| 订购 | `from_year`, `to_year` | 双端包含，整数 1900–2200，单段不超过 12 年 |
| 订购 | `first_volume` | 首年卷号，随后每年加一 |
| 订购 | `issues_per_year` | 单年正刊期数 1–60 |
| 订购 | `numbering`, `first_issue` | `yearly` 按年从 1 起，`continuous` 按出版年度累加，首年首期可指定 |
| 刊名 | `chain`, `title`, `from_year`, `to_year` | 生效年度包含两端，规范化后同刊名每年只有一个映射，同链可登记同年的多个别名 |
| 出版说明 | `id`, `revision` | 说明编号唯一，修订版为 1 起的整数 |
| 出版说明 | `effective_from` | 生效年；该说明的年订购与刊名只可管辖此年及以后 |
| 出版说明 | `rules`, `titles` | 本版订购段与刊名数组，结构同上，可留空由其他版承担 |
| 出版说明 | `transition_until` | 可选的旧刊名过渡截止年，不得早于生效年 |
| 来刊 | `accession` | 物理件验收号，以字符串原样保留前导零，去除两端空格后参与去重 |
| 来刊 | `title`, `year` | 来刊登记刊名和整数出版年，年度按出版年核对 |
| 来刊 | `volume`, `issue` | 字符串，允许全角与前导零，卷期为 1–9999 |
| 来刊 | `kind` | `regular` 正刊默认值，`supplement` 增刊单列 |

期号范围可使用 `-`、`–`、`—`、`~` 或 `至`，包含两端。来刊以验收号分组，同组相同字段视为重放，不同字段保留独立候选。`null`、空字串或空对象记空行，其他坏字段给出字段名并随原值隔离。不使用到达顺序推断卷期。

## 出版说明裁决

提供 `specs` 时按 `effective_from` 升序排列，最晚生效的一份为本次采用，较早的各份继续留存。每份说明只能管辖生效年及以后，各份年份不得重叠，同链相邻说明的卷号与连排期号须衔接。当期号由按年复位改为跨年连排、或启用新刊名时，受影响期位记 `NUMBERING_CHANGED`、`TITLE_CHANGED`，并逐位标明归属说明。新说明的最晚 `transition_until` 内，旧版说明的刊名仍回挂原订阅链，归链依据记 `TRANSITION_TITLE`，不当作未登记或已更替刊名。

说明切换若使订购或刊名不成立，弃用该份说明并回退到上一版可用的说明；被弃说明、原因码与仍采用的说明一并留在结果中，原始清册不因此丢件。两套说明可同时存在，但同刊名不得归属不同订阅链。

## 期位核验

期位键为 `(chain, year, issue)`。卷号由订购规则唯一决定，用于来刊交叉检查。相邻订购段须递增接续卷号，两段都连排时还须接续期号。合期只认合法年度内的完整范围。每个期位通过所有候选确定状态，分为覆盖、缺刊、争议。争议包括多个件号覆盖和同件号不同来刊描述。两种争议均可从到藏记录追溯原始清册。每个期位带 `spec`（归属说明）与 `basis`（`CURRENT_TITLE` 本期说明刊名或 `TRANSITION_TITLE` 过渡期旧刊名）；争议期位另列件号，尚未核清的原件列在隔离区。

## 调用与归档

各阶段接受 `GET /api/<阶段>/<clean|dirty|renewal>` 或 `POST /api/<阶段>`。请求体用 `{"sample":"dirty"}` 或 `{"data":{...}}`，两个来源只能选一个。阶段名为 `orders`、`receipts`、`numbering`、`combined`、`titles`、`specs`、`balance`。

`POST /api/runs` 接受同一请求并保存运行。运行编号为规则版本与规范 JSON 输入摘要的 SHA-256。`GET /api/runs/{id}` 读归档，`POST /api/runs/{id}/rerun` 用归档里的原输入再算。同摘要的重复归档保留首份运行时间与结果，重跑不会把同一件来刊重复计入覆盖。规则版本变化会生成新编号。归档结果含出版说明裁决、受影响期位、归链依据与尚未核清的争议。`GET /api/runs/{id}/export` 下载一份 JSON 凭证，含原始清册和计算证据，归档时间用 UTC。
